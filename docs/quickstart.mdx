# Quickstart

Get started with the Full Stack Test API in just a few minutes.

## Prerequisites

Before you begin, ensure you have:

- Node.js 18+ installed
- MongoDB running locally or a MongoDB Atlas connection
- A REST client like Postman or cURL

## Step 1: Register a New User

Create a new user account by sending a POST request to the register endpoint:

<CodeGroup>

```bash cURL
curl -X POST http://localhost:3000/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "fullName": "John Doe",
    "email": "john.doe@example.com",
    "password": "Password1!"
  }'
```

```javascript JavaScript
const response = await fetch('http://localhost:3000/auth/register', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    fullName: 'John Doe',
    email: 'john.doe@example.com',
    password: 'Password1!',
  }),
});

const data = await response.json();
console.log(data);
```

</CodeGroup>

## Step 2: Login

Authenticate with your credentials to receive a JWT token:

<CodeGroup>

```bash cURL
curl -X POST http://localhost:3000/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "john.doe@example.com",
    "password": "Password1!"
  }'
```

```javascript JavaScript
const response = await fetch('http://localhost:3000/auth/login', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    email: 'john.doe@example.com',
    password: 'Password1!',
  }),
});

const data = await response.json();
const token = data.token;
```

</CodeGroup>

## Step 3: Access Protected Endpoints

Use the JWT token to access protected endpoints:

<CodeGroup>

```bash cURL
curl -X GET http://localhost:3000/auth/me \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

```javascript JavaScript
const response = await fetch('http://localhost:3000/auth/me', {
  headers: {
    'Authorization': `Bearer ${token}`,
  },
});

const profile = await response.json();
console.log(profile);
```

</CodeGroup>
