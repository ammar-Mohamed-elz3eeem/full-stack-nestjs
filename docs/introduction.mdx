# Full Stack Test API

Welcome to the Full Stack Test API documentation. This API provides authentication and user management functionality for the Full Stack Test application.

## Overview

The Full Stack Test API is a RESTful API built with NestJS that provides:

- **User Authentication**: Register new users and authenticate existing users
- **User Management**: Manage user profiles and retrieve user lists (admin only)
- **JWT-based Security**: Secure endpoints using JSON Web Tokens

## Base URL

```
http://localhost:3000
```
